# Partners & Agents — отдельный бот

Это самостоятельный проект; follow-up репозиторий не изменяется. Сейчас добавлен рабочий каркас бота и Telegram Mini App по присланным скриншотам: старт, кнопка «Открыть», разделы агентов, партнёров, проверки контакта, FAQ и поддержки.

## Запуск

1. Создайте нового бота через BotFather и включите для него Mini App/кнопку меню.
2. На Railway создайте **новый сервис из этого проекта**, добавьте переменные из `.env.example`.
3. Сначала получите публичный HTTPS-домен Railway, затем укажите его в `PUBLIC_APP_URL`.
4. В `BOT_TOKEN` вставьте токен нового бота. Токен follow-up использовать нельзя.

Ссылки регистрации, API статистики, правила проверки контактов и тексты FAQ пока являются заглушками — их нужно подключить перед рабочим запуском.

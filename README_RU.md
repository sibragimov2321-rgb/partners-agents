# MELBET Partners

Telegram-бот и Mini App для агентской и партнёрской программы.

## Переменные Railway

```ini
BOT_TOKEN=
DATABASE_URL=
PUBLIC_APP_URL=https://ваш-домен.up.railway.app
SECRET_KEY=
ADMIN_IDS=
SUPPORT_USERNAME=
DOCUMENT_RETENTION_DAYS=365
```

После изменения `PUBLIC_APP_URL` Railway перезапускает сервис. В Telegram отправьте боту `/start` и нажмите «Открыть приложение».

## Состав Mini App

- Агенты и партнёры: формы заявок;
- Рекламные материалы: экран-заготовка для будущих баннеров;
- Проверка контакта и блок-листа;
- FAQ, поддержка и личный кабинет;
- фирменный тёмный интерфейс MELBET Partners с оригинальной графикой.

## Регистрация агента

Новый сценарий сохраняет каждый этап в PostgreSQL:

1. создание и проверка аккаунта;
2. подтверждение депозита;
3. личные данные и документы;
4. данные кассы и источник;
5. финальная проверка и активация.

Паспорт, селфи и подтверждение депозита отдаются только самому пользователю или Telegram ID из `ADMIN_IDS`. Срок хранения задаётся через `DOCUMENT_RETENTION_DAYS`.

Менеджер открывает **Кабинет → Кабинет менеджера**. Там доступны одобрение, запрос исправлений, отклонение, активация и просмотр защищённых документов. Все действия записываются в аудит.

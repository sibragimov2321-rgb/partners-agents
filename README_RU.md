# Partners Agent

Telegram-бот и Mini App для агентской и партнёрской программы.

## Переменные Railway

```ini
BOT_TOKEN=
DATABASE_URL=
PUBLIC_APP_URL=https://ваш-домен.up.railway.app
SECRET_KEY=
ADMIN_IDS=
OWNER_TELEGRAM_ID=
SUPPORT_USERNAME=
DOCUMENT_RETENTION_DAYS=365
```

После изменения `PUBLIC_APP_URL` Railway перезапускает сервис. В Telegram отправьте боту `/start` и нажмите «Открыть приложение».

## Состав Mini App

- Агенты и партнёры: формы заявок;
- Рекламные материалы: экран-заготовка для будущих баннеров;
- Проверка контакта и блок-листа;
- FAQ, поддержка и личный кабинет;
- оригинальный тёмный интерфейс Partners Agent с жёлтым акцентом.

## Регистрация агента

Перед регистрацией пользователь видит описание работы агента, преимущества, требования, список необходимых данных и семь этапов подключения. После кнопки **«Начать регистрацию»** открывается анкета из шести шагов.

Черновик каждого шага сохраняется в PostgreSQL:

1. имя, фамилия, страна и город;
2. телефон, Telegram и email;
3. опыт и ожидаемое количество игроков;
4. место работы, касса и источник;
5. проверка и подтверждение достоверности данных;
6. экран успешной отправки с номером заявки.

Поле страны содержит отдельные группы для основных стран, Кавказа/СНГ и стран Азии. Если нужного варианта нет, агент выбирает **«Другая страна»** и вводит название вручную. Выбранная страна сохраняется в PostgreSQL и отображается менеджеру в заявке и в подтверждённом профиле агента.

Стартовый депозит берётся из таблицы `geo_agent_settings`. Владелец меняет сумму в **Кабинет → Управление → Условия по GEO** без изменения frontend-кода.

Статусы заявки: `draft`, `submitted`, `under_review`, `need_information`, `pre_approved`, `waiting_deposit`, `waiting_documents`, `final_review`, `approved`, `rejected`. Все переходы сохраняются в `agent_application_history` с Telegram ID инициатора, предыдущим и новым статусом, временем и комментарием.

Паспорт, селфи и подтверждение депозита отдаются только самому пользователю или Telegram ID из `ADMIN_IDS`. Срок хранения задаётся через `DOCUMENT_RETENTION_DAYS`.

Менеджер открывает **Кабинет → Кабинет менеджера**. Там доступны начало проверки, запрос информации, предварительное одобрение, открытие депозитного этапа, подтверждение депозита и документов, активация и отклонение с обязательной причиной. Все действия записываются в аудит и историю статусов.

## Доступ менеджеров

Только владелец (`superadmin`) может добавлять и удалять менеджеров. Укажите свой числовой Telegram ID в `OWNER_TELEGRAM_ID`. Если переменная не заполнена, владельцем автоматически считается первый ID из `ADMIN_IDS`. Владелец всегда только один.

Владелец открывает **Кабинет → Управление менеджерами**, вводит Telegram ID сотрудника и нажимает **Дать доступ менеджеру**. Новый менеджер получает доступ к проверке заявок, но не может назначать других менеджеров. Все изменения доступа сохраняются в журнале.

Менеджеров, указанных непосредственно в `ADMIN_IDS`, можно удалить только изменением этой переменной в Railway. Менеджеров, добавленных через приложение, владелец может удалить на том же экране.

То же управление доступно прямо в чате с ботом только владельцу:

- `/add_manager 123456789` — добавить менеджера;
- `/remove_manager 123456789` — удалить менеджера;
- `/managers` — посмотреть список.
